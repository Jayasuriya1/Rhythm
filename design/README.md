## Product design direction
Rhythm's current product brief explicitly chooses **OLED Pitch Black as the default**, with Standard Dark, Light and Follow System alternatives. The visual target is Calm Editorial Wellness: restrained sage/mint accents, excellent typography, generous intentional spacing, clear hierarchy, carefully composed data and native Android interaction. The system should feel polished without looking like a generic card dashboard.

## Operating rules
- Read the product vision and AI workflow before UI changes.
- Treat design tokens as proposed until reviewed on actual devices.
- Do not remove features or change data behavior during visual-only work.
- Do not claim a screen is audited without source and rendered evidence.
- Keep unresolved decisions visible; don't silently convert hypotheses into requirements.
- A feature is not complete because it compiles.
