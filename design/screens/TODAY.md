# Screen Specification — Today

## Goal
Understand today's status and start the next useful action quickly.

## Primary action
Resume or start the next relevant action based on actual user data and clear prioritization.

## Hierarchy
1. Compact greeting/date.
2. Next action / continue.
3. Routine anchor progress.
4. Contextual reminder or quick check-in.
5. Optional sleep/focus/mood summaries.
6. Secondary links.

## Rules
One dominant action. Avoid multiple equal-weight cards. Use open sections for related content. Never fabricate metrics. Missing data says “Not logged” or is omitted. If no task exists, offer a gentle route to choose/create one.

## States
First launch; partial day; active focus; completed anchors; overdue reminder; unavailable data source; loading/database error.

## Acceptance
New users understand purpose at a glance. Start/resume focus is reachable without task administration. Routine progress is plain-language. Every metric has a real stored or connected source.
