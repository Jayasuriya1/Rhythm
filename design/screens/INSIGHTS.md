# Screen Specification — Insights

## Goal
Understand personal patterns over time without metric overload.
## Primary action
Choose a metric and time range.

## Hierarchy
Short factual summary; one primary chart; date range and coverage; supporting history; limitations and missing data.

## Chart requirements
Title, metric, unit, date range and source; clear axes; accessible text summary; stable metric colors; missing values shown as missing, not zero. No causal or diagnostic claims.

## Acceptance
Each chart answers a clear question, is understandable without color, identifies data coverage/source and avoids unsupported health conclusions.
