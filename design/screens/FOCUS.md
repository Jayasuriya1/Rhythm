# Screen Specification — Focus

## Goal
Start and sustain focused work with minimal friction.
## Primary action
Start, resume or pause the timer.

## Hierarchy
1. Timer and mode.
2. Selected task / session intention.
3. Primary timer controls.
4. Park a distraction.
5. Upcoming tasks and lightweight selection.
6. Recent sessions and advanced settings.

## Rules
Start/pause/resume/stop are distinct. Confirm destructive reset when elapsed work may be lost. Task selection must not require category administration. Brain dump returns to timer without losing state. Audio is optional.

## States
Ready, running, paused, break, completed, interrupted; no tasks; selected task removed; audio unavailable; process recreation.

## Acceptance
Timer is focal point. Next action obvious. Configuration does not dominate. Large text remains legible. Critical transitions are tested.
