# Rhythm Product Vision

Rhythm is a private, offline-first daily companion that helps people build steadier routines, focus on meaningful work, record personal wellness signals and manage everyday reminders.

**Promise:** Make the next helpful action clear, and make keeping a simple daily rhythm feel manageable.

## Principles
- Calm, not clinical; supportive, never judgmental.
- Useful before comprehensive; common actions before feature discovery.
- Private by default; explain local storage and data controls honestly.
- Reliable before clever: alarms, reminders, medication logs and timers must behave predictably.
- User agency: configurable goals and reminders; no guilt or streak-shaming.
- Transparent health context: present recorded data, not diagnoses or treatment instructions.
- Inclusive: support accessibility and low-friction interactions.

## Non-goals
Rhythm is not a medical device, diagnostic tool or replacement for clinical care. It must not prescribe medication or treatment, require cloud accounts for core use, or add features merely to increase feature count.

## Success measures
Can a new user identify the next action? Can they start focus and log an anchor or medication entry without confusion? Are alarms reliable? Are data source, privacy, export and restore understandable? Can key tasks be completed with TalkBack and large text? Do users return because the app helps rather than pressures them?

Feature completion requires validated purpose, usable interaction, states, accessibility, persistence, error handling and tests.
