# Feature and UX Priority Backlog

Priorities are hypotheses; re-score after user testing and reliability review.

## P0 — Daily usefulness
- [ ] Today: clear next action and truthful overview.
- [ ] Focus: reliable start/pause/resume/complete.
- [ ] Routine: quick anchor logging.
- [ ] Medication: clear schedule and factual intake log.
- [ ] Sleep/mood: low-friction logging and history.
- [ ] Alarm reliability and permission explanation.
- [ ] Backup/export/restore trustworthiness.
- [ ] First-run onboarding without feature overload.

## P1 — Understanding and retention
- [ ] Insights with meaningful labeled trends.
- [ ] Brain dump capture in seconds.
- [ ] Health Connect provenance, permission and sync feedback.
- [ ] Reminder settings and quiet hours.
- [ ] Accessibility and large-text refinement.

## P2 — Optional enrichment
- [ ] Focus soundscapes and aesthetic themes.
- [ ] Guided meditation refinements.
- [ ] Advanced customization.
- [ ] Web companion exploration after Android workflows stabilize.

## Defer
Duplicated features; dashboards without a user decision; AI health interpretation/treatment suggestions; cloud accounts before demand/privacy model validation; visual effects without usability value.

## Definition of done
User value, UI, behavior, data, accessibility, tests and documentation checked.
